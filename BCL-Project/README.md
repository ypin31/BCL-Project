# BCL

BCL es una aplicación desarrollada en Python que combina un sistema de inicio de sesión con una calculadora y un bloc de notas.

El proyecto cuenta con dos versiones:

- **BCL**: versión básica del proyecto.
- **BCL Persistent**: versión evolucionada con interfaz gráfica y persistencia de datos.

---

## Versiones

### BCL

La versión original de BCL está diseñada como una implementación básica del proyecto.

Incluye:

- Sistema de inicio de sesión.
- Calculadora.
- Bloc de notas.
- Interfaz sencilla de uso.

**Archivo:** `BCL.py`  
**Ejecutable:** `BCL.exe`

---

### BCL Persistent

**BCL Persistent** es una evolución del proyecto original, centrada en mejorar la experiencia de uso y añadir persistencia de datos.

Incluye:

- **Interfaz gráfica** desarrollada con Tkinter.
- **Sistema de inicio de sesión.**
- **Calculadora integrada.**
- **Bloc de notas.**
- **Persistencia de las notas**, permitiendo conservar su contenido entre ejecuciones.
- **Historial de acciones** mediante almacenamiento local.
- Gestión de archivos para guardar y cargar la información.

A diferencia de la versión básica, BCL Persistent permite trabajar con una interfaz gráfica y conservar las notas y el historial después de cerrar la aplicación.

**Archivo:** `BCL_Persistent.py`  
**Ejecutable:** `BCL_Persistent.exe`

---


## Tecnologías

- Python 3
- Tkinter
- Programación orientada a objetos
- Manejo de archivos
- Persistencia de datos
